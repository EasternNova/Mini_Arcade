# 🎮 Advanced Tic-Tac-Toe  
A polished, responsive, and interactive Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**. This project includes multiple game modes, AI difficulty levels, animations, and a clean UI—making it a great portfolio piece showcasing front-end skills.

🔗 **Live Demo:**  
https://prachishaw1.github.io/Tic-Tac-Toe/

## ⭐ Features
- **🎮 Single-player and Two-player modes**  
- **🤖 Smart AI**  
  - Easy (random)  
  - Hard (minimax-based for 3×3, heuristics for larger boards)  
- **🧠 Supports multiple grid sizes**  
  - 3×3  
  - 5×5  
  - 7×7  
- **✨ Animations and winning effects**  
- **🔊 Click, win, and draw sound effects**  
- **📱 Fully responsive design** (works on desktop & mobile)  
- **🗣 Fun character messages**  
- **🔁 Score tracking with localStorage**  
- **🎨 Clean UI with themed panels**
